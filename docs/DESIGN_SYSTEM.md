# MERQO VERTEXA — Design System

## Identity
Futuristic diagnostics laboratory: premium dark theme default, sophisticated
cyber accents, engineering-dashboard clarity.

## Typography
System font stack (Segoe UI). H1 28/600, H2 20/600, body 13/400, mono
(Cascadia Code) for values, IDs and logs.

## Components
Cards (12px radius, subtle border), status pills colored by status, data tables
with sticky headers, charts (sparklines + line charts), dialogs, toasts.
Spacing scale 4/8/12/16/24. Sidebar 240px collapsible. Top bar 48px.

## Themes & accessibility
Dark + light persisted themes; reduced-motion setting disables animations;
keyboard navigable; contrast-checked text; tested at 100%–200% Windows scaling.
